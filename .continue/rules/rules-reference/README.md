# Справочник правил 1С (ITC / std)

Эти файлы **не загружаются** как активные правила Cursor/Continue. Они сохранены как справочник полных текстов стандартов (std441, std444, std447, std448, std453, std454, std455, std640, std641, std647).

По умолчанию при работе с кодом 1С используется краткая выжимка: **.continue/rules/1C-BSL-кратко.md**

При необходимости можно открыть нужный файл из `itc/` вручную или сослаться на него в запросе.
